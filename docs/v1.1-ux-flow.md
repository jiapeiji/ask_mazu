## 2. 新功能子流程

### 2.1 文化日记流程

```mermaid
flowchart LR
    A[投掷结果<br/>签文卡片] --> B[折叠区: 写点感想]
    B --> C{用户输入文字}
    C -- 不写 --> D[点 关闭]
    C -- 写 --> E[点 保存]
    E --> F[写入 Hive<br/>journal_box]
    F --> G[弹 SnackBar: 已保存]
    G --> H[跳回 Home]

    I[历史页<br/>History Page] --> J{tab 切换}
    J --> K[问事 tab<br/>原 records 流]
    J --> L[日记 tab<br/>records + journal 流]
    L --> M[每条卡片:<br/>签文图 + 诗文 +<br/>用户反思 + 日期]
```

**关键 UX**:写反思默认折叠,展开后**可选**填(0 字也能保存)— 减少用户摩擦。

### 2.2 妈祖文化模块流程

```mermaid
flowchart LR
    A[主屏右下角<br/>圆形妈祖图标] --> B[Mazu Culture Page]
    H[设置 → 关于妈祖] --> B
    B --> C[PageView<br/>5 屏可滑动]
    C --> D1[屏 1: 妈祖生平]
    C --> D2[屏 2: 全球信仰分布]
    C --> D3[屏 3: 投杯筊起源]
    C --> D4[屏 4: 60 支签来源]
    C --> D5[屏 5: 海外华人传承]
    D5 --> E[完结提示<br/>返回主屏]
```

**关键 UX**:5 屏用 PageView 滑动,**首屏是大图 + 大字**,不要文字密集。
